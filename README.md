# Lanchonete Flow

Crie um sistema web completo para gerenciamento de uma lanchonete.

O sistema deve ser desenvolvido em fases, com arquitetura organizada e código pronto para produção. Use o Supabase como backend principal, incluindo autenticação, banco de dados, políticas de segurança e armazenamento quando necessário.

Nesta primeira etapa, faça somente o planejamento e a fundação do projeto.

Objetivo:

Criar um sistema para administrar produtos, categorias, clientes, pedidos, pagamentos e relatórios de uma lanchonete.

Requisitos gerais:

- Interface em português do Brasil.

- Layout responsivo para computador, tablet e celular.

- Visual profissional, simples e rápido.

- Código organizado e fácil de manter.

- Não usar dados fictícios permanentes.

- Não colocar senhas, tokens ou chaves diretamente no código.

- Usar variáveis de ambiente para credenciais.

- Usar Supabase como banco de dados.

- Preparar a estrutura para autenticação de usuários.

- Preparar a aplicação para futura integração com serviços externos.

- Não criar ainda funcionalidades fora do escopo definido.

Nesta primeira etapa, crie somente:

1. Estrutura inicial do projeto.

2. Layout principal da aplicação.

3. Navegação básica.

4. Página inicial/dashboard ainda sem dados reais.

5. Página de login visual, sem concluir toda a autenticação.

6. Organização das áreas:

   - Dashboard

   - Produtos

   - Categorias

   - Clientes

   - Pedidos

   - Pagamentos

   - Relatórios

   - Configurações

7. Arquivo ou documentação descrevendo a arquitetura.

8. Lista clara das próximas fases.

Não crie ainda:

- Tabelas do banco.

- Migrations.

- CRUD completo.

- Dados de produção.

- Integrações externas.

- Deploy na VPS.

- Funcionalidades de IA.

- Relatórios finais.

- Regras financeiras definitivas.

Ao final, informe:

- O que foi criado.

- A estrutura das páginas.

- A tecnologia utilizada.

- O que ainda está pendente.

- Qual será a próxima fase recomendada.
