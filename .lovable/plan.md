# Usar Supabase como banco deste projeto

## Situação atual

O projeto já está conectado ao banco integrado do Lovable Cloud, baseado em Supabase. Não é necessário selecionar ou informar outro projeto, URL ou chave.

## Próximo passo quando solicitado

- Definir as tabelas de produtos, categorias, clientes, pedidos e pagamentos.
- Criar as alterações do banco por migrations.
- Ativar políticas de segurança e permissões adequadas.
- Implementar autenticação e conectar as telas aos dados reais.

## Limite deste passo

Nenhuma tabela, autenticação ou funcionalidade da Fase 2 será criada apenas para confirmar a conexão existente.
