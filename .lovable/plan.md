# Novo projeto para o Trilha do Sabor

## Objetivo

Criar uma cópia independente da Fase 1 em outro projeto Lovable e preparar esse novo projeto para usar o banco externo “trilha-do-sabor”, sem alterar nem apagar este projeto atual.

## Situação confirmada

- Este projeto atual continuará intacto, com o Lovable Cloud já ativo.
- Ainda não existe outro projeto de destino acessível chamado “trilha-do-sabor” neste workspace.
- O único outro projeto acessível é “Estande Financial Hub”, que não será modificado.

## Etapas

1. **Criar o projeto de destino**
   - Criar um novo projeto Lovable vazio com o nome “Trilha do Sabor”.
   - Não ativar nem configurar um banco novo antes de importar a fundação.

2. **Copiar somente a Fase 1**
   - Transferir layout, navegação, páginas, estilos e documentação.
   - Manter todas as telas em português e os estados vazios honestos.
   - Não copiar credenciais, dados ou configuração do banco deste projeto.

3. **Conectar o banco externo**
   - Configurar no novo projeto as credenciais públicas do projeto externo pelo fluxo seguro disponível.
   - Manter chaves privadas fora do código.
   - Confirmar a conexão sem criar tabelas ou alterar dados existentes.

4. **Validar a cópia**
   - Conferir as nove rotas da Fase 1 em computador, tablet e celular.
   - Verificar navegação, foco de teclado, metadados e ausência de erros.
   - Confirmar que este projeto original permaneceu sem alterações.

## Limites

- Não iniciar a Fase 2.
- Não criar tabelas, migrations, políticas, CRUD ou autenticação funcional.
- Não importar dados do banco externo nesta etapa.
- Não modificar o projeto “Estande Financial Hub”.

## Ação necessária antes da execução

O usuário precisa criar o novo projeto “Trilha do Sabor” no dashboard. Depois que ele aparecer no workspace, a fundação poderá ser transferida e a conexão externa preparada.
